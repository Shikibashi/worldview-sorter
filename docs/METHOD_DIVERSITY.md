# Method-diversity milestone

> Historical milestone for bank v0.6 (301 items), not the current bank size or production-content baseline. See [the PR #1 content audit](CONTENT_EFFICIENCY_AUDIT.md) for bank v0.9 (562 items).

Bank v0.6 adds a third primary-role indicator to every headline construct.

The objective is not merely to increase item count. Third indicators were preferentially written using a different response method or elicitation frame where that makes conceptual sense.

## Current result

The v0.6 bank contains **301 candidate items**.

Headline constructs:

- 60 total;
- 60 have at least 3 primary-role indicators;
- 56 use at least 2 distinct response scales or formats.

Primary-tier constructs:

- 62 total;
- all remain at or above the 2-primary-indicator floor.

## Method-diverse additions

Examples include:

- moral disagreement and moral-objectivity vignettes;
- rescue and promise-conflict cases in normative ethics;
- direct moral-relevance ratings for the six moral foundations;
- evidence/theory and expert/self-judgment tradeoffs in epistemology;
- categorical naturalism, physicalism, teleology, and meaning questions;
- deterministic-replay and manipulation vignettes for agency;
- afterlife, supernatural, and cosmic-purpose diagnostics;
- individual/group, pluralism, and human/nature tradeoffs;
- legitimacy, political obligation, rights, decentralization, distribution, property, and market-coordination scenarios.

## Deliberate single-scale exceptions

Four headline constructs currently use only `importance5`:

- `VA01` Self-direction: thought
- `VA03` Stimulation
- `VA04` Hedonism
- `VA15` Benevolence: caring

These belong to the Schwartz-style personal-values module.

Using repeated importance judgments there is intentional. A forced vignette or agreement statement would change the response task and could make the value module less comparable internally.

Method diversity is therefore a design goal, not an automatic requirement that every construct use multiple response formats.

## Why separate method diversity from depth

A construct can have:

- many items using one method;
- few items using many methods;
- both;
- neither.

These are different properties.

The project therefore reports:

1. primary-indicator depth;
2. response-scale diversity;
3. later, empirical local dependence and method effects.

They should not be collapsed into one quality score.

## Remaining work

The v0.6 bank is still candidate material.

The next major evidence source should be cognitive review. In particular, method-diverse items need review for whether changes in response format also change the construct respondents think they are answering.

After cognitive review, the remaining expansion toward the long-term research-bank target should be guided by construct breadth and review findings rather than by equal item counts.
