# Tradition or criterion proposal prompts

Copy `model-change.json`; use `objectType: tradition` or `criterion`.

- Define scope and distinguish defining, characteristic, disputed, and non-entailing commitments.
- Cite claims at commitment level, including primary and academic secondary work where appropriate; document internal disagreement.
- Map only to actual interpreted propositions, showing measured, partial, unmeasured, and unsuitable criteria.
- Test nearest neighbors, divergence, missing doctrine, overlapping traditions, and no established affinity. Version the catalog.
