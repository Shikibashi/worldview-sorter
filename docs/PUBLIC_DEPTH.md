# Uniform public-construct depth milestone

## Bank v0.7

The active candidate bank now contains **363 items**.

All public-facing constructs share the same minimum development floor:

- 60 / 60 headline constructs have at least 3 primary-role indicators.
- 62 / 62 primary-tier constructs have at least 3 primary-role indicators.
- 122 / 122 public-facing constructs therefore have at least 3 standalone primary indicators.

Secondary cross-loadings do not count toward this floor.

## Expansion batch 0.5

This stage adds 62 items, one third primary indicator for every primary-tier construct.

The batch emphasizes method diversity where useful:

- moral and political vignettes;
- paired tradeoffs;
- categorical diagnostics;
- direct value-importance items;
- causal-attribution scenarios;
- distributive, property, justice, punishment, and institutional scenarios.

## Cognitive review

Cognitive review is **not an active project requirement or promotion gate**.

Earlier cognitive-review infrastructure has been removed from the active branch configuration. The project proceeds through item development and later empirical pilot/psychometric evaluation without requiring that stage.

## What three indicators mean

Three candidate items are still not evidence that a construct is a valid unidimensional scale.

The floor exists so later pilot analysis can evaluate a construct with more than one accidental wording.

Later evidence may show that:

- some items should be removed;
- a construct splits into multiple factors;
- two constructs collapse;
- a construct needs more items;
- categorical or vignette responses work better than a latent scale;
- a construct should be removed from the public instrument.
